IMAGES GUIDE — Your Parish Name Website
=========================================

Replace the placeholder images below with real photos from your church.
All images should be in JPG or PNG format and optimised for web
(use tinypng.com or squoosh.app to compress before uploading).


REQUIRED IMAGES
───────────────

1. hero-bg.jpg
   Usage    : Full-screen background behind the hero section
   Size     : 1920 x 1080 px minimum (landscape)
   Content  : Church exterior, stained glass, or congregation photo
   Tip      : Darker/moodier images work best — the text overlay needs contrast

2. church-interior.jpg
   Usage    : Photo in the "About Our Parish" section
   Size     : 800 x 600 px (4:3 ratio, landscape)
   Content  : Church interior, altar, nave, or sanctuary

3. logo.png
   Usage    : Logo in the navigation bar
   Size     : 120 x 120 px (square, will be displayed as circle)
   Format   : PNG with transparent background preferred
   Content  : Church crest, cross logo, or parish seal


STAFF PHOTOS (optional but recommended)
───────────────────────────────────────

4. priest-photo.jpg      — Parish Priest
5. deacon-photo.jpg      — Deacon
6. secretary-photo.jpg   — Parish Secretary
7. dre-photo.jpg         — Director of Religious Education

   Size for all staff photos : 400 x 400 px (square)
   They will be displayed as circles on the website.
   If a photo is missing, a cross icon placeholder will appear instead.


TIPS
────

- Rename photos exactly as listed above (lowercase, correct extension)
- Save all files in this /images/ folder
- After replacing images, refresh the browser to see changes
- For best results, compress images to under 300KB each
  Free tools: https://tinypng.com  |  https://squoosh.app

- To add more staff photos, update the <img src="..."> tags in index.html
  in the "Clergy & Staff" section, and add the new photos here.
